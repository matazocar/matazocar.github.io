After being in BCC two weeks ago, this is what I brought back with me and would like to keep doing research in

## Temporal Graphs

Actually, one topic that seemed very interesting to me was temporal graphs. I don't know much about it, but it seems that they evolve as a process and sometimes the edges are present and sometimes not. You have complete information about when an edge will appear and when it will not. (I might be wrong, have to recheck the survey).

Given this, many interesting questions arise
- Temporal Ramsey number (or how many vertices you need to find a monochromatic clique).
- Temporal largest clique number.
- Temporal largest path number.
- Temporal pretty much whatever you can think in the classic setting.

This opens a very interesting branch of research in which I'd like to invest some time thinking.

## Bootstrap percolation

Moving on, there is another topic that caught my eye some time ago. This was "bootstrap precolation".

Essentially, it's a process in which you keep adding edges such that those edges keep creating new copies of a certain fixed graph. This has many questions in itself.
- How many stages does this process have?
- Does this process finish? (it does)
- Does this process always finish in a complete graph? (apparently not)
- How does it behave depending on the fixed graph we are studying.

And, in a very lucky turn of events, Tibor Szabó gave a very nice talk about the topic, in which he (along with other researchers) made some new discoveries around this object. 

I don't have any special question in mind right now about it, but I think is a very interesting area of research and would like to keep learning about it.

## Euclidean Ramsey theory

There was another thing that didn't appeal my taste very much, but my advisor gave some pointers to me about, which is Euclidean Ramsey theory. Apparently, there are some Ramsey and some Canonical questions that could be asked about colouring $\mathbb R^n$ in large dimensions. Thus, this seems rather interesting in some contexts, but it's still a work in progress. We'll see about it.

We'll keep the hard work and (hopefully) produce some new knowledge in any of these problems!
